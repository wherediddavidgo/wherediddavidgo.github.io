iv. What should alpha_pair be to ensure that alpha_family is 0.05?¶

Where k is the number of groups among which comparisons are made, the number of pair comparisons c is given by:
c = k (k - 1) / 2

k = 5
c = 10

alpha_family = 1 - (1 - alpha_pair) ^ c
alpha_pair = 0.00512

ii. Calculate Cohen's d to identify effect size in differences between groups.¶

In [8]:
d1 = 0
d3 = 0
d4 = 0
d15 = 0
d18 = 0

def cohen_d(g0, g1):
    mean0 = np.mean(g0)
    mean1 = np.mean(g1)

    stdev = np.std(
        np.concatenate([g0, g1])
    )

    return (mean0 - mean1) / stdev


for n in range(len(hucs)):
    for m in range(len(hucs)):
        if n <= m:
            break

        h0 = hucs[n]
        h1 = hucs[m]

iii. Infer practical significance of differences between groups.¶

Summing the absolute value of Cohen's d per region reveals that HUCs 15 and 1 differ most from the other regions. It makes sense that HUC 15 in the southern Basin and Range would differ from the others since it is by far the most arid. It also makes sense that HUC 1 in New England differs from the others as precipitation is high and relatively evenly distributed through the year. HUC 18 (California) shows the smallest sum Cohen's d, which could be interpreted to mean the least different from the others. This may be due to the fact that flows in HUC 18 are the most variable (see boxplot from 1. i.), and Cohen's d is a function of 1 / standard deviation.
